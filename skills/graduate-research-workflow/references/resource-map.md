# Research Resource Map

## Canonical long-term index

If available, open your own literature search and writing resource index in Obsidian.

Read the index when recommending a tool, teaching the user's research workflow, or locating saved media notes. Treat tool capabilities, prices, and web links as changeable; verify them when they affect the request.

The companion source note is your local note on traceable AI-assisted literature review. Read it when the user asks how the workflow was derived or requests the original teaching notes. These two notes are source material; the `SKILL.md` is the executable agent instruction.

## Routing

| Research need | Preferred route |
| --- | --- |
| Discover related papers and citation networks | Google Scholar, discipline databases, institutional repositories, Connected Papers, ResearchRabbit |
| Verify citation metadata | Publisher page, DOI/Crossref record, university repository |
| Manage citations | Zotero |
| Query authorized PDFs or synthesize supplied material | PDF tooling; SciSpace or NotebookLM only after the user authorizes any upload |
| Write or revise | Use a source/claim audit before presenting research prose as evidence-based |

For a proposal audit, record `draft claim/location | original source/page | evidence level | actual support | action`. Mark data availability, model assumptions, validation plan, and claimed benefits separately; bibliographic correctness alone does not establish that the proposed study is feasible.

Connected Papers and ResearchRabbit help discover candidates; they do not replace metadata or full-text verification. Zotero is the citation-library source of truth after the user imports or approves records.
