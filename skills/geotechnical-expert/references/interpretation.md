# 試驗與工程判讀檢核

適用土壤／材料試驗、鑽探、現地檢測、監測與力學計算；依本次問題取所需欄位，不要求每次完整報告。

## 試驗輸入先對齊

- 試驗名稱與目的、適用標準及版本、試體／現地位置與深度、日期、取樣與擾動狀態。
- 材料分類、飽和及壓密歷史、載重與排水階段、速率、量測量及單位；缺項不得自行填補為已知。
- 分清量測值、校正值、換算值、相關式估計與設計選值；試驗認證或單點合格不等於全場代表性。
- 發現漏零、單位或符號矛盾，保留原值並列問題；不能把內部算式推回的可能數字冒稱已核實原題。

## 土壤與界面

- 總應力／有效應力、總孔壓／超額增量分清；排水不等於u＝0，不排水不保證正超額孔壓。
- su、c′、φ′不可因單位相同而互換；UU、CU、CD需辨識各階段，不只看名稱。應力路徑先定義座標及總／有效狀態。
- 土與土試驗不直接代表土與混凝土／鋼界面；辨識δ、界面附著項與α的意義，記錄粗糙度、密實度、正應力、排水與位移範圍。
- SPT N值與修正後N值、相關式適用範圍須分清；不能用單一N值證明強度、壓縮性及所有設計參數。

## 力學與驗算

- 應力分布、合力與力矩分開；沿壁高積壓力得到每米壁長力，力臂以實際取矩點為準。H/3只屬相應三角形，不套所有分布。
- 土壓係數不是力；主／被動由牆相對土體的移動與動員程度判斷。不得重複加入已包含的水壓。
- 水頭先定同一基準，再求壓力頭與孔壓；滲流梯度與滲透係數不同，砂湧、內部侵蝕與上舉需分別檢核。
- 力平衡、強度折減及尺寸放大等安全係數並非同一定義；不把課堂門檻直接搬到現地。
- 動力及土壤結構互制問題先定荷重歷程、頻率／阻尼、邊界與模型維度；缺資料時只解釋方法，不能假稱已完成動力分析。

## 判讀交付

提供「來源定位 → 觀察／計算 → 所支持結論 → 不能推論之處 → 尚缺資料」。有異常時區分儀器／資料問題、模型假設與可能物理現象，不先斷言單一原因。簡單基準模型通過只證明其實際驗證範圍，不升格為真實場址驗證。
