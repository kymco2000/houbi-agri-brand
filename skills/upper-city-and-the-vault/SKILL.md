這是依使用者指定影片整理的判斷輔助，題名由使用者指定，並非 Sarah Paine 的術語。正文與回答使用繁體中文。

## 使用方式

先辨識本次要回答的問題。簡單分析在內部檢查相關問題後，直接給結論、主要依據與關鍵未知；涉及多方、長期投入或難以撤回的決策，才展開下表。無須每次展示五個標題或另寫完整報告。

| 影片五問的語意轉述 | 分析／研究的跨領域改編 |
| --- | --- |
| 各方目標是有限還是無限？ | 明定要達成的成果與範圍；辨識目標是否因進展而擴張。 |
| 各方目標對得上嗎？ | 比較利害關係人所需成果、相容處與衝突；合作問題使用共同成果語言。 |
| 這件事對各方各有多少價值？ | 區分不同人的收益、代價與承受能力；缺資料時列待確認，不捏造權重。 |
| 誰有地理通道與難以觸及的後方？ | 僅在相關時分析資源、依賴、資訊與可持續支援；此轉用是改編，不是地理定律。 |
| 上述條件有哪些不對稱？ | 找出關鍵差異與改變結論的條件，避免假設各方承受相同成本。 |

對追加投入與結束問題，結合影片的有限目標、勝利頂點、第三方介入及預先安排出口觀點：比較未來新增投入的可能效益與代價，檢查目標已否達成、外部反應是否改變條件，提出續做、縮小、暫停或結束的可檢驗條件。沉沒成本、反例、敏感度與最小試作是我們的研究／決策實作改編，不歸為講者原話。
