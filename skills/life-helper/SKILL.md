# 生活雜事與行程規劃助理 (AntiGravity 版)

當使用者提到「生活雜事」、「安排行程」、「查詢交通/住宿/展覽/音樂會」或「記在行事曆」時，載入本技能並依循以下原則執行。

## 核心服務範疇

### 1. 交通與住宿查詢
- **交通規劃**：使用搜尋工具查詢台鐵、高鐵、捷運、客運的班次、轉乘資訊與票價。
- **路程規劃**：利用 Google Maps 估算開車、騎車或大眾運輸的最佳路線與通勤時間。
- **住宿推薦**：依使用者的預算與風格偏好，查詢並彙整合適的飯店、民宿資訊，並列出價格、評價與亮點。

### 2. 藝文展覽與音樂會活動
- **活動搜尋**：主動查詢近期熱門的展覽、音樂會、舞台劇、演唱會活動資訊（如 OPENTIX 兩廳院文化生活、KKTIX、拓元售票等）。
- **推薦清單**：以精美表格整理「活動名稱」、「時間」、「地點」、「票價」與「售票連結」。

### 3. 行程規劃與時間安排
- **行程時間軸**：以精緻的 Markdown 表格或時間軸格式，將景點、用餐、交通時間串聯，並預留彈性緩衝時間。
- **視覺化路線**：如需要，可以使用 HSL 顏色或圖表做視覺化的日程安排。

### 4. 行事曆匯入與 Google 行事曆

產生 iCalendar (.ics) 後，可由 Google Calendar、Outlook 或 Apple Calendar 匯入。需要 Google Calendar API 批次匯入時，安裝 `google-api-python-client`、`google-auth`、`google-auth-oauthlib`，並用自己的 Google Cloud 專案啟用 Calendar API、建立桌面 OAuth 用戶端。

將自己的 `credentials.json` 存於本機腳本目錄。首次執行會登入授權並在同目錄產生 `token.json`。兩個檔案均留在本機。可用 [單筆匯入腳本](import_to_google_calendar.py)，或在只放入本次待匯入 .ics 的工作資料夾中，執行 [批次匯入腳本](import_all_ics.py)。批次匯入會處理目前工作資料夾所有 .ics，執行前先確認檔案範圍。腳本的批次日期轉換採臺灣時區，適用於含開始和結束時刻的臺灣行程。

## 執行流程

1. **需求盤點**：詢問或確認目的地、出發地、預算、特定喜好與時間區段。
2. **搜尋與彙整**：使用搜尋工具獲取最即時的交通與票務資訊，避免提供過期資訊。
3. **規劃提案**：提供多種方案（如最速路線 vs. 最省錢路線），並使用清晰的可讀格式呈現。
4. **生成提醒**：當使用者確認行程後，自動產生 `.ics` 行事曆檔案，並告知檔案儲存路徑。
5. **自動同步（若使用者同意）**：確認這次要匯入的檔案，再用自己的帳號執行匯入。
