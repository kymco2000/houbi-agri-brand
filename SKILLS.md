# 個人全域技能

本頁收錄專案作者自訂的全域技能。挑選需要的技能，將指令中的 `SKILL_NAME` 換成清單內的名稱。

```powershell
gh skill install kymco2000/houbi-agri-brand SKILL_NAME --agent codex --scope user
```

重新開啟 Codex 後，可輸入 `$技能名稱` 呼叫。內建與第三方外掛由各自平台安裝。需要 Vault、NotebookLM、Firebase 或 Google Calendar 的技能，請用自己的資料夾和帳號設定。
